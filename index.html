Cómo subir Casita Sebita 3D a GitHub Pages

Tu modelo fue optimizado de 69.7 MB a 12.3 MB para entrar directo sin Git LFS ni servidores externos

¡No necesitas configurar nada extra! Descarga el archivo casita_sebita_github_pages.zip que te adjunté en el chat. Adentro ya están listos index.html, casitaSebita.glb (12.3 MB) y README.md.
  1. Crea un repositorio nuevo y público en github.com/new (por ejemplo casita-sebita-3d).
  2. Descomprime el .zip en una carpeta de tu PC y sube los archivos arrastrándolos desde el navegador o ejecutando estos comandos en PowerShell/CMD:
git init
git add index.html casitaSebita.glb README.md
git commit -m "Subir espacio 3D Casita Sebita con colisiones y fisicas"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/casita-sebita-3d.git
git push -u origin main

3. En tu repositorio de GitHub entra a Settings → Pages, en Branch elige main y carpeta / (root), y pulsa Save. En 60 segundos tu casa estará online en https://tu_usuario.github.io/casita-sebita-3d/.
